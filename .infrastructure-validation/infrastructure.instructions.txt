Review all warnings and parameter values before deployment. This is a limited first-release export, not a full-fidelity blueprint backup.
Each template is an independent resource-group-scoped deployment. Resource groups and subscriptions are NOT created. The separate deployment-scopes.json records suggested diagram boundaries, not executable ARM metadata. Select the correct existing subscription and resource group for EACH file; edit parameter values for the target environment. Deployment scope is selected by the deployment command, not by a resource-name parameter.
ARM: az deployment group create --subscription <subscription-id> --resource-group <existing-rg> --template-file <template.json> --parameters @<template.parameters.json>
Bicep: az deployment group create --subscription <subscription-id> --resource-group <existing-rg> --template-file <template.bicep> --parameters @<template.parameters.json>
Alternatively use --parameters <template.bicepparam> with a recent Azure CLI/Bicep version. JSON parameters and .bicepparam are alternatives, not inputs to combine.
All template parameters are required. Missing values are intentionally absent from parameter files: supply them yourself; no placeholder credentials or invented required settings are provided. Use incremental mode and review Azure what-if before deployment. Do not use complete mode. Region, SKU availability, naming, CIDRs, policies and application compatibility need Azure validation. Parent ordering is emitted, but no permissions, role assignments or security links are inferred. Private endpoints, identities, diagnostic settings and advanced networking are unsupported.
